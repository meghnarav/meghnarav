## Projects

### [koncertify](https://github.com/meghnarav/koncertify)
A ticket booking service built to test how well applications hold up under flash-sale traffic spikes.
- Prevents double-booking and overselling using Redis distributed locks and atomic Lua scripts instead of heavy database-level locks.
- Backed by PostgreSQL with transactional isolation to keep booking states consistent when multiple users grab the same seat.
- **Stack:** TypeScript, Redis, PostgreSQL

### [ohmnic](https://github.com/meghnarav/ohmnic)
A real-time telemetry pipeline for streaming EV battery sensor data.
- Ingests high-frequency time-series points through a serverless pipeline with minimal ingestion delay.
- Runs live anomaly detection on battery metrics and uses SHAP values to flag what caused an irregular reading.
- **Stack:** TypeScript, Serverless, Python (ML)
